FIGURE 2: Complexity-stratified analysis grid (Stage III)

This multi-panel figure presents a comprehensive robustness analysis stratified by model complexity (number of free parameters, n_free). Each row corresponds to a complexity tier (n_free = 4, 5, 6, 7, 8), displaying three complementary analytical perspectives:

PANEL A – Parameter correlations with principal components
Shows the correlation of each kinetic parameter's fixation state (0=free, 1=fixed) with the first two principal components (PC1 and PC2) derived from the robustness index space (AICc, MNCI, RSQ2, GSS). Blue bars represent PC1 correlations, green bars represent PC2 correlations. The percentage of variance explained by each component is shown in the legend. Parameters with high absolute correlations strongly influence the positioning of models in the robustness landscape.

Interpretation: Positive correlations indicate that fixing the parameter moves models in the positive direction along that PC axis; negative correlations indicate movement in the negative direction. This panel reveals which structural decisions (parameter fixations) drive variation in overall model performance within each complexity tier.

PANEL B – PCA biplot (robustness landscape)
Displays models in the two-dimensional space defined by PC1 and PC2 of the robustness indices. Gray points represent all viable models in the tier; blue points highlight top-quartile models (RSQ2 ≥ q75). Green vectors show the contribution of each robustness index (AICc, MNCI, RSQ2, GSS) to the principal components. Black vectors represent individual parameter fixation patterns, showing how each parameter's state correlates with model positioning.

For tier 7, model 1750 is marked with an orange star to facilitate cross-referencing with Figure 3 and downstream validation analyses. This model represents a recommended fixation policy that balances parsimony (7 fixed parameters) with robust predictive performance across multiple robustness criteria.

Interpretation: Proximity between points indicates similar robustness profiles. The angular separation between green index vectors reveals the degree of concordance between different performance metrics. Parameter vectors aligned with index vectors suggest that fixing those parameters tends to improve those metrics; orthogonal or opposing vectors indicate trade-offs or neutral effects.

PANEL C – Delta-Index heatmap (% change upon fixation)
Quantifies the average percent change in each robustness index when a parameter is fixed versus free, within the tier. Values are computed as: Δ(%) = 100 × (mean_fixed - mean_free) / mean_free. The color scale (blue-white-red) highlights beneficial fixations (negative Δ for AICc/MNCI, positive for RSQ2/GSS) versus costly ones.

Interpretation: A negative value for AICc or MNCI indicates that fixing the parameter improves (reduces) these penalty-based indices, which is desirable. A positive value for RSQ2 or GSS indicates improved fit or sensitivity, also desirable. Parameters with consistently favorable signs across multiple indices are strong candidates for fixation. Large absolute values signal parameters where the fixation decision has substantial impact on model quality.

TIER-SPECIFIC NOTES:
- Tiers with fewer than 2 top-quartile models or extreme complexity levels (n_free = 3, 9) are excluded to maintain statistical reliability and manuscript focus.
- The analysis uses all viable Stage II models within each tier for PC construction (not just top-quartile), ensuring the robustness landscape reflects the full structural diversity at that complexity level.
- Top-quartile membership is defined globally (RSQ2 ≥ 0.75 quantile across all tiers) to maintain a consistent quality threshold for cross-tier comparisons.

INTEGRATION WITH OTHER FIGURES:
- Figure 1 (histogram) provides context on the overall distribution of fixed parameters across all viable models.
- Figure 3 (fixation heatmap) offers a global view of parameter fixation patterns, with the top-quartile subset and model 1750 highlighted for visual consistency with this grid.
- Figure 4 (ElasticNet coefficients) complements Panel C by providing a regularized, multivariate perspective on parameter-index associations, accounting for collinearity.

METHODOLOGICAL DETAILS:
- PCA: Standardized robustness indices (AICc and MNCI sign-reversed for directionality alignment), 2 components retained.
- Parameter vectors in Panel B: Pearson correlations between each parameter's fixation state (standardized) and PC scores.
- Delta-Index: Mean-based percent differences with bootstrap 95% confidence intervals (not shown in heatmap but available in supplementary CSV files).
- Robustness indices: AICc (Akaike Information Criterion corrected), MNCI (Mean Normalized Confidence Interval from Monte Carlo), RSQ2 (coefficient of determination), GSS (Global Sensitivity Sum).

This figure supports the identification of parsimony-robust parameter fixation strategies, guiding the selection of reduced-order models that retain predictive skill while minimizing identifiability issues and computational overhead in fermentation kinetics applications.
